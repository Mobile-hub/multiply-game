# Multiply 🚀

Videojuego pixel 8-bit de temática espacial para repasar las tablas de multiplicar del 1 al 10.

## Jugar

```sh
make open    # abre index.html en el navegador
make serve   # o sírvelo en http://localhost:8000
```

No necesita instalación, dependencias ni conexión a internet.
